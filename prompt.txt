Build a comprehensive React travel planning web app using Tailwind CSS, shadcn/ui, and lucide-react. The app simulates a multi-page routing system and complex state management. Please render all UI text, placeholders, and mock data in Brazilian Portuguese.

Core Data Structure & State Management:

    A "Trip" (Viagem) contains multiple "Days" (Roteiros/Dias).

    Two Levels of Unallocated Items:

        Global Unallocated Cart: Items added without a preferred day.

        Daily Unallocated Cart: Items assigned to a specific day, but without a specific time yet.

    Time-Blocked Timeline: Allocated items are grouped into colored shifts: Manhã (Yellow, 06h-12h), Tarde (Orange, 12h-18h), Noite (Dark Blue, 18h-00h), Madrugada (Purple, 00h-06h).

1. Persistent Top Navigation Bar

    Always visible at the top.

    Left: Logo ("rota").

    Center: Navigation tabs: "Explorar", "Minhas Viagens", "Perfil", "Configurações".

    Right: A shopping cart icon with a numerical badge (counter) showing the total number of unallocated items. Next to it, keep the floating three-way View Toggle from your previous iteration: "Planejamento" (List/Global), "Dividido" (Split), and "Mapa" (Map-only).

2. Screen: Explorar (Feed)

    Empty State: A hero section with a "Criar nova viagem" button. Clicking it opens a modal to set a destination (e.g., Rio de Janeiro) and number of days (e.g., 4).

    Active State: A masonry or grid feed of Attraction Cards (clean design: photo, place name, hours, neighborhood).

    Add Action: Clicking the "+" button on a card opens a popover asking for "Dia preferido" (dropdown: Any day, Day 1, Day 2...) and "Horário preferido". Adding it increments the cart counter in the navbar and sends the item to either the Global Unallocated list or a Daily Unallocated list based on the selection.

3. Screen: Minhas Viagens (Global Planning View - "Planejamento" Toggle)
This is the master assembly board.

    Left Panel (Global Cart): A vertical list titled "Não Alocados da Viagem". Displays items with no preferred day. Above the list, a primary button: "Distribuir Toda a Viagem" (Simulates allocating these items smartly across all days).

    Right Panel (Day Carousel): A large card showing one specific day at a time, with Left/Right arrows in the header to navigate (e.g., "Dia 1", "Dia 2").

    Inside the Day Card:

        A sub-section titled "Não Alocados deste Dia" (items assigned to this day but missing time).

        A button "Gerar Roteiro do Dia" (Simulates optimizing just this day's unallocated items).

        The chronological timeline showing the color-coded time blocks (Manhã, Tarde, Noite, Madrugada).

4. Screens: Dividido (Split) & Mapa (Map-only)
These views are for micro-adjustments of an already built day.

    Day Selector: A sub-navbar appears just below the main header with tabs for the days (e.g., "Dia 1 | Dia 2 | Dia 3 | Dia 4").

    Divided View Layout: Left panel shows the chronological timeline (draggable cards) strictly for the selected day. Right panel shows the map.

    Map Only View: Full-screen map strictly for the selected day.

Create a mock visual representation of the map for the selected day.

    Map UI should have toggle buttons: "Aproximar" (Zoom In) and "Afastar" (Zoom Out).

    Zoom In View: Display numbered pins (1, 2, 3...) colored by their time-block shift. Show route lines connecting them with 60% opacity of the respective color and small directional arrows.
